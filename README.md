# goit-pycore-hw-03

Домашнє завдання з Python Core (4 задачі).

## Що виконано

- `task1.py` — функція `get_days_from_today(date)`:
  - рахує різницю в днях між переданою датою та сьогоднішньою;
  - працює з форматом `YYYY-MM-DD`;
  - має обробку помилки формату дати.

- `task2.py` — функція `get_numbers_ticket(min, max, quantity)`:
  - генерує унікальні випадкові числа в заданому діапазоні;
  - повертає відсортований список;
  - при невалідних параметрах повертає порожній список `[]`.

- `task3.py` — функція `normalize_phone_number(phone_number)`:
  - нормалізує номер телефону до стандартного формату;
  - видаляє зайві символи;
  - додає префікс `+38`, якщо міжнародний код відсутній.

- `task4.py` — функція `get_upcoming_birthdays(users)`:
  - повертає список привітань на 7 днів вперед (включно з поточним днем);
  - переносить привітання з вихідних на понеділок;
  - повертає список словників з `name` та `congratulation_date`.

## Швидкий запуск

```bash
python3 task2.py
python3 task3.py
python3 task4.py
```
